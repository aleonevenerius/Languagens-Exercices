# Languages-Exercises
This repository is all about programming language exercises.

# Step One - Elementary

* 1.1 Code a programme which shows "Hello, World!";
* 1.2 Read the user's name and show a welcome message;
* 1.3 Read two numbers and show the sum, subtraction, multiplication and division;
* 1.4 Convert a temperature from Celsius to Fahrenheit;
* 1.5 Calculate the rectangle's area;
* 1.6 Inspect if a number is even or a single number;
* 1.7 Inspect if a number is positive, negative or zero;
* 1.8 Read the user's age and inform if they are an adult or not;
* 1.9 Compute the average of three values and inform if the student was approved.
* 1.10 Code a simple calculator.

# Step Two - Intermediary

* 2.1 Contar a frequência de palavras.
* 2.2 Encontrar o segundo maior número.
* 2.3 Validar uma senha.
* 2.4 Criar um sistema de cadastro.
* 2.5 Verificar se uma frase é palíndromo.
* 2.6 Analisar notas de alunos.
* 2.7 Simular um caixa eletrônico.
* 2.8 Criar um jogo de adivinhação.
* 2.9 Implementar um algoritmo de ordenação.
* 2.10 Criar um sistema bancário.
